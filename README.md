## Техническое задание: Космические защитники

## 1. Общие сведения

Название: Terradom
Жанр: Пошаговая стратегия (4X)
Платформа: Python 3.10+, Arcade
Команда: Левищев Георгий, Кошелев Артём, Дорофеев Андрей

## 1. Общие сведения

### 1.1. Наименование проекта
**Космические защитники** — 2D аркадный космический шутер с элементами roguelite.

### 1.2. Назначение проекта
Разработка десктопной игры для:
- Тренировки реакции и стратегического мышления
- Достижения высоких результатов в системе лидеров
- Демонстрации навыков работы с Python/Arcade

### 1.3. Технологический стек

| Компонент | Технология | Версия |
|-----------|-----------|--------|
| Язык программирования | Python | 3.8+ |
| Игровой движок | Arcade | 2.6+ |
| База данных | SQLite3 | встроенная |

### 1.4. Глоссарий

| Термин | Определение |
|--------|-------------|
| `Wave` | Волна — группа врагов и препятствий, спавнящихся одновременно |
| `Budget` | Бюджет волны — условные единицы для балансировки сложности |
| `ToughEnemy` | Усиленный враг с повышенным здоровьем и способностью стрелять |
| `Passable Wall` | Проходимое препятствие, отражающее снаряды игрока |

## 2. Функциональные требования

### 2.1. Игровой процесс

#### 2.1.1. Управление игроком

| Действие | Управление | Описание |
|----------|-----------|----------|
| 🎮 Перемещение | Движение мыши | Корабль следует за курсором в пределах экрана |
| 🔫 Стрельба | ЛКМ | Выпуск снаряда вверх с кулдауном `0.1с` |
| 📊 Таблица лидеров | `TAB` | Переключение отображения рекордов |
| 🔄 Рестарт | `R` (после Game Over) | Перезапуск игры с сбросом прогресса |
| ✍️ Ввод имени | Клавиатура | Ввод никнейма для сохранения результата |

#### 2.1.2. Игровые объекты

##### 👤 Игрок (`WarShip`)
```
Характеристики
- Спрайт: "images/x-wing.png"
- Масштаб: 0.5x
- Ограничения: границы экрана (800×600)
- Условие поражения:
  • Столкновение с вражеским снарядом
  • Столкновение с врагом, достигшим y=0
  • Столкновение с непроходимой стеной (passable=False)
```

## 4. Технические требования (согласно модулю)

- Использование SpriteList, Camera, ParticleSystem.
- Звуковое сопровождение.
- Хранение данных в JSON.
